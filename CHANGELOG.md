# Changelog

## 1.0.0

Initial public self-hosted release.

- Native SwiftUI / HealthKit app with configurable HTTPS endpoint and IANA timezone.
- Upload and wake-upload App Intents, Keychain token storage and vacation mode.
- Standard-library receiver with authenticated batch uploads, history, sleep interval aggregation and wake event queue.
- AstrBot health summary tool, command, history dashboard and opt-in wake greeting via the main agent.
- Container/systemd/proxy examples, detailed setup and protocol docs, synthetic tests and unsigned iOS build scripts.
- No hosted service, personal server configuration, real health fixtures, development certificates or provisioning profiles.
